# Требования при реализации интеграции с умным домофоном и шлагбаумом #

1. Взаимодействие между сервисами PropDevelopment и сервисами партнера происходит с mTLS через HTTPS (выбор протокола для стриминга видео с камеры домофона зависит от возможностей партнера)

2. Адаптер для взаимодействия с сервисом партнера в контуре PropDevelopment может вызываться только мобильным приложением, а также другими сервисами внутри tenant-core-app.

3. При передаче команд к устройствам и данных от устройств - не передается никаких персональных данных пользователей-собственников. 

4. Определение устройства происходит в контуре PropDevelopment, авторизация для доступа к устройству в сервисе партнера обеспечена либо токенами, либо с помощью технических обезличенных учетных записей в сервисе партнера.

5. Сервис партнера хранит информацию о биометрии (биометрических векторах лиц) только в зашифрованном виде. При распознавании лиц происходит шифрование распознанных биометрических векторов и сравнение с данными в БД.

6. Сервис партнера хранит информацию о номерах автомобилей только в зашифрованном виде. При распознавании номеров происходит шифрование распознанных данных и сравнение с данными в БД.

7. Сервис партнера не хранит видеозаписи с умного домофона

8. При подключении собственников к новым услугам компания PropDevelopment запрашивает дополнительное согласие на обработку перс данных: биометрия лица и номер авто

9. При отключении собственника от услуг - в сервисе партнера должно происходить удаление зашифрованных данных о биометрии лица и номерах авто

10. Сервис партнера может вызывать только адаптер для взаимодействия, находящийся внутри tenant-core-app. При коммуникациях от сервиса партнера должны быть установлены лимиты и таймауты
